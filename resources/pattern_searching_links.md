# Pattern Searching Resources

This file contains links and references for learning **pattern searching algorithms** used in text processing and bioinformatics.

---

## 🧩 Single-Pattern Algorithms

1. **Naive Algorithm**  
   - Tutorial: [GeeksforGeeks – Naive Algorithm](https://www.geeksforgeeks.org/naive-algorithm-for-pattern-searching/)  
   - Description: Simple brute-force search for a single pattern.

2. **Morris-Pratt Algorithm (MP)**  
   - Tutorial: [GeeksforGeeks – Morris-Pratt Algorithm](https://www.geeksforgeeks.org/morris-pratt-algorithm/)  
   - Description: Efficient single-pattern search using prefix preprocessing.

3. **Boyer-Moore Algorithm**  
   - Tutorial: [GeeksforGeeks – Boyer-Moore Algorithm](https://www.geeksforgeeks.org/boyer-moore-algorithm-for-pattern-searching/)  
   - Description: Skips unmatched characters to speed up single-pattern search.

4. **Rabin-Karp Algorithm**  
   - Tutorial: [GeeksforGeeks – Rabin-Karp Algorithm](https://www.geeksforgeeks.org/rabin-karp-algorithm-for-pattern-searching/)  
   - Description: Uses hashing to efficiently search for a single pattern.

---

## 🧩 Multiple-Pattern Algorithms

1. **Rabin-Karp (Multiple Patterns)**  
   - Tutorial: [GeeksforGeeks – Rabin-Karp Multiple Patterns](https://www.geeksforgeeks.org/rabin-karp-algorithm-for-pattern-searching/)  
   - Description: Hash-based search for multiple patterns simultaneously.

2. **Aho-Corasick Algorithm**  
   - Tutorial: [GeeksforGeeks – Aho-Corasick](https://www.geeksforgeeks.org/aho-corasick-algorithm-pattern-searching/)  
   - Description: Builds a finite automaton to search multiple patterns in linear time.

3. **Wu-Manber Algorithm**  
   - Tutorial: [GeeksforGeeks – Wu-Manber Algorithm](https://www.geeksforgeeks.org/wu-manber-algorithm-for-multiple-pattern-searching/)  
   - Description: Optimized multiple-pattern search using block-based shifts.

4. **Commentz-Walter Algorithm**  
   - Tutorial: [GeeksforGeeks – Commentz-Walter Algorithm](https://www.geeksforgeeks.org/commentz-walter-algorithm/)  
   - Description: Combines Boyer-Moore logic with multiple-pattern optimization.
